# AMY_BABI4005
This is a repository for BABI 4005

In this branch, you will find all the necessary documents for "Assignment 6: Project Reflection" for Amy Goldlist

This project is an analysis of the Global Box Office Performance of Movies (2000–2024)
This dataset was provided by Aditya Jilla posted on Kaggle (https://www.kaggle.com/datasets/aditya126/movies-box-office-dataset-2000-2024?resource=download) and it provides a detailed analysis of global box office performance from 2000 to 2024. It includes information on movies released during this period, covering key metrics such as release dates, genres, production budgets, worldwide gross, and more. (Jilla, 2025)
